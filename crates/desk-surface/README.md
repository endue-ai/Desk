# desk-surface

The surface protocol (`specs/surface/v0`, ADR 0141) as Rust types: the one contract between the
compositor and anything that draws a surface: a web surface's host (CEF off-screen, #52) and a native
plugin's process (#59, ADR 0154). `serde` only by default, so the compositor, `desk-web` and a native
plugin all depend on it; the `native` feature adds a native plugin's transport for both sides.

## Public API

- `CompositorMessage`: lifecycle (`create`, `resize`, `show`, `hide`, `sleep`, `wake`, `destroy`),
  `release`, `pace`, pointer, key and focus input, IME, drag and drop (ADR 0119), accessibility, and
  `desk.message` (a page message for a native plugin).
- `SurfaceMessage`: `ready`, `died`, `title`, `attach` (a `SurfaceTexture` and its handle: IOSurface,
  D3D11 shared handle or DMA-BUF), `rate`, `cursor`, IME, drags, `a11y.update`, `plugin.message`.
- `generated`: every type of the spec, GENERATED by `just codegen`; never edit it by hand. `env`: the
  variables a native plugin's process starts with.
- `native` (feature `native`, `specs/surface/v0/native.md`): `lines` (JSON lines, at most 1 MiB);
  `mach` (macOS: `PortService` checks in the desk's port and takes a right only from the process it
  expects, `PortSender` sends one, `bgra_surface`); `plugin::Plugin` (a plugin connects from its
  environment, hears the desk and answers pings itself, sends frames, title and page messages);
  `bridge::Bridge::call` (the bridge on `desk.sock`'s wire). Feature `native-wgpu` (macOS):
  `iosurface::SharedTexture`, an IOSurface as a wgpu texture to render into.

## Test

```bash
cargo test -p desk-surface --all-features
```

`tests/vectors.rs` judges every vector of `specs/surface/v0/vectors` by the schemas, reads each valid
one through the generated types and writes it back unchanged, and checks that the types refuse what
is wrong in shape; `packages/bridge/src/surface.contract.test.ts` holds the TypeScript side to the
same vectors. The native modules test their lines, pings and Mach rights in place.
