# desk-bridge

Rust side of the Desk bridge: the types generated from `specs/bridge/v0` and `specs/plugin/v0`.

Layer: Desk bridge (see `docs/architecture.md`). Status: generated types only; traits arrive with the core.

## Public API

- Request, response and event types: `BridgeRequest`, `BridgeResponse`, `BridgeEvent`, and one
  `*Request` / `*Params` / `*Result` per method (`FsReadRequest`, `ProcSpawnParams`, ...).
- The permission vocabulary (`Permission` and one struct per permission) and `PluginManifest`.
- `SCHEMAS`: every bridge and plugin JSON Schema as `($id, json)` for validation at run time.
- `NAME`: the crate name.

`src/generated.rs` is GENERATED by `just codegen`; never edit it by hand.

## Testing

```bash
cargo test -p desk-bridge
```

`tests/contract.rs` checks the shared vectors and round trips; `tests/wit.rs` checks that
`specs/wit/desk-host.wit` is a subset of the bridge methods.
