# desk-brain

Brain client types generated from `specs/brain/v0/openapi.yaml`. The `Brain` trait arrives with the first
client (`desk-brain-endue`).

Layer: Rust core (see `docs/architecture.md`). Status: generated types only.

## Public API

- Sessions: `Session`, `CreateSessionRequest`, `ClientInfo`.
- Turns: `TurnRequest`, `UserMessage`, `TurnEvent` (one struct per event), `ToolCall`, `ToolResultRequest`.
- Leases: `Lease`, `LeaseHolder`, `LeaseAcquireRequest`, `LeaseRenewRequest`.
- Errors: `BrainError`, `BrainErrorCode`.
- `BRAIN_SCHEMA_JSON`: the component schemas as one JSON Schema document.

`src/generated.rs` is GENERATED by `just codegen`; never edit it by hand.

## Testing

```bash
cargo test -p desk-brain
```

`tests/contract.rs` checks the shared vectors in `specs/brain/v0/vectors` and the round trips.
