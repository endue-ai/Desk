# desk-brain

The brain contract for Rust: the `Brain` trait (one method per operation of
`specs/brain/v0/openapi.yaml`) and the types generated from it. Clients implement the trait; desk-core
only ever talks to the trait.

Layer: Rust core (see `docs/architecture.md`).

## Public API

- `Brain`: `create_session`, `get_session`, `create_turn` and `submit_tool_result` (turn streams hand
  each `TurnEvent` to a callback), `get_lease`, `acquire_lease`, `renew_lease`, `release_lease`; the
  agent directory: `list_agents(&AgentQuery)`, `get_agent_card`, `list_spaces`,
  `list_a2a_tasks(&TaskQuery)`. The directory has defaults for a brain without one (desk-brain-local):
  empty pages, no spaces, and 404 `not_found` for every agent card.
- `AgentQuery`, `TaskQuery`: the filters and page of the two lists; `None` leaves a parameter out.
- `BrainFailure`: `Refused { status, error }` (the brain said no: lease conflicts among them),
  `Unreachable` (no connection, or the stream broke), `Protocol` (an answer outside the contract).
- Generated types: `Session`, `TurnRequest`, `TurnEvent`, `ToolCall`, `ToolResultRequest`, `Lease`,
  `LeaseHolder`, `LeaseAcquireRequest`, `LeaseRenewRequest`, `BrainError`, `BrainErrorCode`, `Agent`,
  `AgentList`, `AgentCard`, `Space`, `SpaceList`, `A2ATask`, `A2ATaskList`, `Pagination` and more.
- `BRAIN_SCHEMA_JSON`: the component schemas as one JSON Schema document.

`src/generated.rs` is GENERATED by `just codegen`; never edit it by hand.

## Testing

```bash
cargo test -p desk-brain
```

`tests/contract.rs` checks the shared vectors and the round trips. `tests/conformance.rs` starts
`examples/brain-echo` (needs Node) and checks every response and stream event against the contract's
schemas, the request vectors, lease conflicts and a conversation through `desk-brain-endue`.
`tests/directory.rs` does the same for the agent directory: filters, pages, refusals and `HttpBrain`.
