# セキュリティポリシー

## 脆弱性の報告

公開の issue は作成しないでください。次のいずれかの方法で、非公開で報告してください。

- 件名に「security」を含めて team@endue.ai にメールする。
- または、このリポジトリの Security タブにある GitHub の「Report a vulnerability」ボタンを使う。

見つけた内容、再現手順、影響を受けるバージョンと OS、想定される影響を記載してください。

## 報告後の流れ

| ステップ | 目標 |
| --- | --- |
| 受領の連絡 | 3 営業日以内 |
| 初回の評価と深刻度の判定 | 10 営業日以内 |
| 修正のリリース | 深刻度に応じてできるだけ早く |
| 一般への公開 | 修正のリリース時。遅くとも報告から 90 日後 |

ご希望がない限り、報告者はリリースノートでクレジットします。

## サポート対象のバージョン

Desk は 1.0 より前の段階です。セキュリティ修正を受けるのは、各チャンネル（stable、beta、canary）の最新リリースのみです。

## 対象範囲

対象：デスクトップアプリ、Rust クレート、TypeScript パッケージ、組み込みプラグイン、ブリッジの権限モデル（プラグインやエージェントが権限なしにプリミティブへ到達できることは脆弱性です）。

対象外：サードパーティ製のプラグイン、およびこのリポジトリ外のサービス（これらは同じアドレスで endue に報告してください）。
