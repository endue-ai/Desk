# 安全策略

## 报告漏洞

请不要提交公开 issue。请通过以下任一方式私下报告：

- 发送邮件至 team@endue.ai，并在主题中注明 “security”。
- 或者在本仓库的 Security 标签页中，使用 GitHub 的 “Report a vulnerability” 按钮。

请说明你发现了什么、如何复现、受影响的版本和操作系统，以及你预计的影响。

## 后续流程

| 步骤 | 目标 |
| --- | --- |
| 确认收到 | 3 个工作日内 |
| 初步评估并确定严重程度 | 10 个工作日内 |
| 发布修复 | 按严重程度的要求尽快发布 |
| 公开披露 | 修复发布时，最迟在报告后 90 天 |

除非你要求不署名，我们会在发布说明中致谢报告者。

## 支持的版本

Desk 尚处于 1.0 之前。只有各渠道（stable、beta、canary）的最新版本会收到安全修复。

## 范围

范围内：桌面应用、Rust crate、TypeScript 包、内置插件，以及桥接层权限模型（插件或智能体未经授权访问原语即属于漏洞）。

范围外：第三方插件，以及本仓库之外的服务（这些问题请发送到同一地址，报告给 endue）。
