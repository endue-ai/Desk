# Governance

## Today

endue Desk has a single maintainer, Team endue. The maintainer reviews and merges pull requests, decides
releases, and owns the protected areas of the repository (`.github/workflows/`, `specs/`, `brand/`).

## How decisions are made

- Day-to-day changes are decided in pull requests.
- Decisions that are hard to reverse are written as ADRs in `docs/adr/` and merged like any other change,
  so the reasoning is public and can be challenged later with a new ADR.
- The design source of truth is `docs/ko/desk-structure.md`. When code and the design disagree, an ADR
  records the decision and the design document is updated.

## Changing this

When regular contributors appear, maintainers will be added by an ADR that also updates this file and
`.github/CODEOWNERS`.
