# endue assets

| File | Use |
| --- | --- |
| `app-icon.svg` | The app icon (512×512): the white mark on brand ink `#17151F`, as https://endue.ai/design/app-icon.svg serves it. `just app-icons` renders the desk's icons in `apps/desk/shell/icons/` from it |

Use the mark as it is: don't redraw it or change the ratio of the star to the ring. The logo gradient and
its colours belong to the logo, so the icon stays white on ink (https://endue.ai/design/brand).

These files are brand assets, not source code: see `../LICENSE`. Forks rename and replace them, then run
`just app-icons`.
