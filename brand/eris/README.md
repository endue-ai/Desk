# Eris assets

Eris is endue's secretary (E.R.I.S. — Endue's Ridiculously Impressive Secretary). She has no face: a geodesic
sphere that is hollow at the centre and dense at the rim, with one gold face. Dysnomia, her moon, is a small
octahedron that orbits at the lower right.

| File | Use |
| --- | --- |
| `eris-balanced.svg` | Default body (520×560 viewBox). Used by the opening scene and the status badge |
| `eris-airy.svg` · `eris-dense.svg` | Lighter and heavier variants of the same geometry |
| `dysnomia.svg` | The moon (64×64) |
| `state-idle.svg` · `state-listening.svg` · `state-thinking.svg` · `state-done.svg` · `state-heads-up.svg` · `state-oops.svg` | Status poses for the sidebar / notifications |

Palette: faces `#2c2836`, edges `#e9edf4` at 50 % opacity, gold face `#f5e2b4 → #d4a85f`, Eris text colour
`#e8c98a` (token `persona-eris`). Background `#141416`.

These files are brand assets, not source code: see `../LICENSE`. Forks rename and replace them.
A moving reference of how they are used is in `docs/reference/eris-opening-prototype.html`.
