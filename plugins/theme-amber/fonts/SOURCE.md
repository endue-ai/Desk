# Fonts

IBM Plex Mono, the variable web fonts (axis `wght` 100–700), copied unchanged from the upstream
repository's release `@ibm/plex-mono-variable@1.0.0` (`fonts/complete/woff2/`) and renamed: the theme
schema allows no spaces in a path. Unmodified, so the Reserved Font Name "Plex" stays the family name.
Licence: SIL Open Font License 1.1 (`OFL.txt`, the release's `license.txt`). No subset: each file is far
under the 2 MiB a theme asset may have, and Hangul falls back to the stack's other fonts.
