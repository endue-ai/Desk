# Fonts

Literata, the variable web fonts (axes `opsz` 7–72 and `wght` 200–900), copied unchanged from the
upstream repository at tag `3.103` and renamed: the theme schema allows no brackets or commas in a path.
Licence: SIL Open Font License 1.1 (`OFL.txt`, from the same tag). No subset: each file is far under the
2 MiB a theme asset may have, and Hangul falls back to the stack's Korean serif fonts.
