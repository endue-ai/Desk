# @endue-ai/bridge

TypeScript client for the Desk bridge, typed from `specs/bridge`, `specs/plugin` and `specs/brain`.

Layer: Desk bridge (see `docs/architecture.md`). Status: generated types only; the client and the tauri
and browser adapters arrive with the app.

## Public API

- Every bridge, plugin and brain type: `BridgeRequest`, `BridgeEvent`, `Permission`, `PluginManifest`,
  `TurnEvent`, `Lease`, ...
- `BridgeMethodMap`: method name → `{ params, result }`; `BridgeMethod`; `BRIDGE_METHODS`.
- `brainSchema`: the brain component schemas as one JSON Schema document.
- `NAME`: the package name.

`src/generated.ts` and `src/brain.generated.ts` are GENERATED by `just codegen`; never edit them by hand.

## Testing

```bash
pnpm exec vitest run packages/bridge
```

`src/contract.test.ts` checks the shared vectors with Ajv and that the generated types agree with the
schemas.
